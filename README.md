# dontwait.fyi

A one-pager for sending to people who hold meetings for late arrivals.

Live at **[dontwait.fyi](https://dontwait.fyi)** — hosted on GitHub Pages.

In the tradition of [nohello.net](https://nohello.net) and [noagendameeting.com](https://noagendameeting.com).

---

## Development

Single file: `index.html`. No build step, no dependencies beyond Google Fonts.

Open it directly in a browser:

```
open index.html
```

## Deployment

Push to the `main` branch. GitHub Pages serves `index.html` automatically.

```
git add index.html
git commit -m "your message"
git push
```
